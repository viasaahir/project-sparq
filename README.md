# RoleArc - AI-Powered Job Board

RoleArc is a modern job board application that uses AI to help job seekers find their perfect role. The application features an engaging user interface with smooth animations and a seamless user experience.

## Features

### Resume Module
- Resume upload & parsing
- AI-powered job recommendations
- LLM-based resume improvement suggestions
- Skills gap analysis
- Resume optimization tips

### Job Board Module
- Advanced filtering system (Hiring Cafe style)
- Detailed job listings
- Save/favorite functionality
- Application tracking
- Enhanced search capabilities

## Tech Stack

- **Frontend**: React + Vite
- **UI**: Tailwind CSS + HeadlessUI
- **Animation**: Framer Motion
- **Icons**: HeroIcons, React Icons

## Getting Started

1. Clone the repository:
```bash
git clone <repository-url>
cd job-board
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5174](http://localhost:5174) in your browser
